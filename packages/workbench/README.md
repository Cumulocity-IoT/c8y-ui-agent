# @cumulocity-iot/c8y-ui-workbench

MCP server for the C8Y UI Agent. It previews a Cumulocity Web SDK app on the emulated tenant of the Cumulocity UI SDK and proves regressions with e2e runs.

Not ready for use yet. Planned tools: `preview_up`, `prove_regression`, `screenshot`, `check`.

Source and documentation: [Cumulocity-IoT/c8y-ui-agent](https://github.com/Cumulocity-IoT/c8y-ui-agent).
